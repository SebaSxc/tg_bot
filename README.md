# ClassSignUpBot

Небольшой Telegram-бот для записи учеников на занятия.

Идея простая: ученик заходит в бота, выбирает день и время, записывается на слот, а преподаватель может посмотреть все записи или при необходимости всё сбросить.

## Что умеет бот

- записывать на свободные слоты
- показывать пользователю его текущие записи
- переносить запись на другой день или время
- отменять запись
- показывать преподавателю все записи
- сохранять данные между перезапусками
- автоматически убирать уже прошедшие слоты

## Как это работает

В боте есть обычный пользователь и преподаватель.

- Обычный пользователь может записаться, посмотреть свои записи, перенести или отменить запись.
- Преподаватель может делать всё то же самое, но ещё видит список всех записей и кнопку сброса.

Кто считается преподавателем, определяется через `TEACHER_ID`.

## Структура проекта

Проект специально разложен не слишком сложно, чтобы в нём можно было быстро разобраться.

- `class_signup_bot.py` - точка входа, именно этот файл запускается
- `bot/app.py` - создание приложения и подключение хендлеров
- `bot/config.py` - конфиг, слоты, `TELEGRAM_BOT_TOKEN`, `TEACHER_ID`
- `bot/state.py` - сохранение и загрузка состояния из `bot_state.json`
- `bot/helpers.py` - вспомогательные функции для времени и форматирования
- `bot/handlers/common.py` - общее меню и логика ввода имени
- `bot/handlers/user.py` - пользовательские действия
- `bot/handlers/admin.py` - действия преподавателя

## Что нужно для запуска

Нужно две вещи:

- `TELEGRAM_BOT_TOKEN` - токен бота из BotFather
- `TEACHER_ID` - Telegram ID преподавателя, которому будут доступны админские функции

Если коротко:

- токен отвечает за то, чтобы программа вообще могла работать как Telegram-бот
- `TEACHER_ID` отвечает за права преподавателя внутри бота

## Быстрый запуск через терминал

Открываешь терминал в папке проекта и пишешь:

```bash
cd /Users/main/Desktop/ClassSignUpBot
source venv/bin/activate
export TELEGRAM_BOT_TOKEN="твой_токен"
export TEACHER_ID="твой_telegram_id"
python class_signup_bot.py
```

Если всё нормально, в терминале появится:

```text
Бот запущен...
```

## Запуск в VS Code

Если не хочется каждый раз руками писать команды, можно запускать бота прямо кнопкой в VS Code.

В проект уже добавлен `launch.json`, поэтому есть 2 варианта:

- `Run Bot (Prompt Token)` - VS Code сам спросит токен и `TEACHER_ID`
- `Run Bot (.env)` - VS Code возьмёт значения из файла `.env`

### Вариант 1. Через запрос значений

1. Открой проект в VS Code
2. Перейди в `Run and Debug`
3. Выбери `Run Bot (Prompt Token)`
4. Нажми `Run`
5. Вставь токен и свой Telegram ID

### Вариант 2. Через `.env`

Создай рядом с проектом файл `.env` на основе `.env.example`.

Пример:

```env
TELEGRAM_BOT_TOKEN=твой_новый_токен_из_BotFather
TEACHER_ID=123456789
```

После этого в VS Code можно просто выбрать `Run Bot (.env)` и запускать без лишних вопросов.

## Где взять нужные данные

### `TELEGRAM_BOT_TOKEN`

Это токен самого бота. Его выдаёт `@BotFather`.

Как получить:

1. Открыть Telegram
2. Найти `@BotFather`
3. Выбрать своего бота
4. Получить токен через `API Token` или команду `/token`

### `TEACHER_ID`

Это обычный Telegram user ID преподавателя.

Проще всего получить его через бота `@userinfobot`: просто пишешь ему сообщение, и он присылает твой ID.

## Где хранятся данные

Состояние бота хранится в файле `bot_state.json`.

Там лежат:

- имена пользователей
- текущие записи
- время слотов

То есть если бот перезапустить, записи не пропадут.

## Важные замечания

- Токен бота не нужно хранить прямо в коде.
- Если токен уже где-то светился, лучше перевыпустить его через BotFather.
- Файл `.env` не должен попадать в git.
- `bot_state.json` создаётся автоматически во время работы.

## Если что-то не запускается

Проверь по порядку:

1. Активировано ли виртуальное окружение `venv`
2. Указан ли `TELEGRAM_BOT_TOKEN`
3. Правильный ли `TEACHER_ID`
4. Установлены ли зависимости в `venv`
5. Нет ли старого или битого токена
